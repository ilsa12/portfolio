# Ilsa Javed — AI Engineer Portfolio

React + Vite + Tailwind CSS (v3).

```
npm install
npm run dev
```

Sab content `src/data.ts` mein hai (email, about, skills, experience, projects). Sab se pehle `EMAIL` change karo.

Deploy: `npm run build` phir `dist/` folder Vercel / Netlify par upload kar do.
